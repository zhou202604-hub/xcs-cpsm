企业微信自建应用

配置保存后，成员在企业微信点击应用会自动走 OAuth2 登录，并获取其姓名。
启用企业微信登录
📌 在企业微信管理后台需要配置
  1. 「应用管理 → 自建应用」新建应用 → 填入应用名/Logo → 可见范围选择全员或指定部门
  2. 进入应用详情页 → 「开发者接口 → 网页授权及 JS-SDK」→ 可信域名填写：material.your-company.com（必须 HTTPS，与上面回调地址域名一致）
  3. 「应用主页 → 主页 URL」填写：https://material.your-company.com/
  4. 把上面页面看到的 CorpId / AgentId / Secret 填到本页保存即可
